Cyber Rider

Cyber Rider is a cyberpunk-themed endless runner developed in Unity (C#) and published as a WebGL build.
This project showcases my ability to design and program engaging gameplay systems for casual browser-based experiences.

🎮 Gameplay

Ride a futuristic motorbike through a neon-lit cyberpunk city.

Collect coins and power-ups to extend runs and boost scores.

Unlock new motorbike paint styles in the in-game shop.

Progressive difficulty to keep players challenged.

🛠️ Tech & Features

Developed with Unity 6 (C#).

Target platform: WebGL.
